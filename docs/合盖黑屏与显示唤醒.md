# 合盖后开盖黑屏（显示器睡眠唤醒失败）

Tahoe 26.7.1 下，屏幕黑掉但系统仍在运行的排查与处理记录。
适用于 WhateverXe 0.6.1 / Graphics 0.3.2，Iris Xe（8086:9A49）内屏 eDP。

## 现象

1. 合盖后屏幕关闭，再打开盖子：**屏幕一直黑，按键、触控板都没有反应**；
2. 闲置一段时间显示器自动关闭后再亮起，也可能黑屏；
3. 但系统本身没有死：SSH、Tailscale 都能连上，命令可以执行，扬声器、麦克风和网络都正常；
4. 重启后显示立即恢复正常。

## 原因

显卡驱动在内屏从睡眠唤醒时做 eDP 链路训练（link training）失败，
framebuffer 把内屏下线，窗口服务器没有可用的显示输出，于是黑屏：

```text
[IGFB][ERROR][AUX] ddi = 0 Time out: 0x8d40023f
[IGFB][ERROR][LINK_TRAINING] writeAUX failed: 0xe00002d6
[IGFB][ERROR][LINK_TRAINING] readAUX failed: 0xe00002d8
[IGFB][ERROR][LINK_TRAINING] Phase 1 of link training failed - notifying AGDC to take display offline
[IGFB][ERROR][DISPLAY] FB0: Hardware mode set failed, err = 0xe00002bc
[IGFB][ERROR][DISPLAY] FB0 is not enabled
[IGFB][WARN][DISPLAY] Hotplug received on closable display - bailing out
```

判定方法：

```sh
sudo log show --last 10m --style compact | grep -iE "LINK_TRAINING|FB0 is not enabled|Hotplug received"
sudo ioreg -n AppleBacklightDisplay -r -d 1 | grep -o '"bklt"={[^}]*}'
pmset -g assertions | grep -iE 'PreventUserIdleDisplaySleep|PreventDisplaySleep'
```

`bklt` 的 value 为 0 表示背光已经关闭；日志出现上面的 `LINK_TRAINING` / `FB0 is not enabled`
即可确认是本问题，不是死机、不是麦克风或 Wi-Fi 驱动。

这是 WhateverXe 显示驱动在 eDP 唤醒路径上的缺陷，不是配置错误。
截至 2026-11-01，WEX 0.6.1 已是最新版本（见 WhateverXe CHANGELOG），暂无上游修复版本。

## 解决办法（本机采用）

思路：**不让显示器进入睡眠**，eDP 就不需要重新做链路训练。
合盖时显示器保持点亮（合上看不到），开盖立即就可以用。

```sh
sudo pmset -a disablesleep 1 displaysleep 0 sleep 0 lidwake 1
```

| 设置 | 作用 |
| --- | --- |
| `disablesleep 1` | 合盖时系统不进入睡眠，显示器也不进入睡眠 |
| `displaysleep 0` | 闲置时不关闭显示器 |
| `sleep 0` | 系统不休眠 |
| `lidwake 1` | 允许开盖唤醒 |

再用两个系统级任务长驻保持，避免设置被系统或其它程序重置
（本机出现过 `SleepDisabled` 被改回 0 的情况）：

### 1. 防睡眠断言 `com.user.caffeinate`

`/Library/LaunchDaemons/com.user.caffeinate.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.user.caffeinate</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/caffeinate</string>
        <string>-d</string>
        <string>-i</string>
        <string>-s</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
```

### 2. 电源设置维持 `com.user.powermgmt-enforce`

脚本 `/usr/local/bin/enforce-pmset.sh`：

```sh
#!/bin/sh
CUR=$(/usr/bin/pmset -g 2>/dev/null | /usr/bin/awk '/SleepDisabled/{print $2; exit}')
if [ "$CUR" != "1" ]; then
  /usr/bin/pmset -a disablesleep 1 >/dev/null 2>&1
  /usr/bin/pmset -a displaysleep 0 sleep 0 lidwake 1 >/dev/null 2>&1
  /usr/bin/logger -t enforce-pmset "re-applied disablesleep=1 (was $CUR)"
fi
exit 0
```

`/Library/LaunchDaemons/com.user.powermgmt-enforce.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.user.powermgmt-enforce</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/enforce-pmset.sh</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>StartInterval</key>
    <integer>30</integer>
</dict>
</plist>
```

安装与校验：

```sh
sudo chown root:wheel /usr/local/bin/enforce-pmset.sh
sudo chmod 755 /usr/local/bin/enforce-pmset.sh
sudo chown root:wheel /Library/LaunchDaemons/com.user.caffeinate.plist
sudo chown root:wheel /Library/LaunchDaemons/com.user.powermgmt-enforce.plist
sudo launchctl bootstrap system /Library/LaunchDaemons/com.user.caffeinate.plist
sudo launchctl bootstrap system /Library/LaunchDaemons/com.user.powermgmt-enforce.plist
pmset -g | grep -E 'SleepDisabled|displaysleep'
pmset -g assertions | grep -iE 'PreventUserIdleDisplaySleep'
```

`SleepDisabled` 应为 1，且能看到 caffeinate 持有的 `PreventUserIdleDisplaySleep` 断言。

### 补充说明

- UU远程 的「防睡眠」开关本质也是加同一类电源断言，可以作为补充；
- 合盖时内屏背光保持点亮（合上看不到）：**LCD 没有烧屏风险**，
  但会耗电并轻微发热，建议插着电、放在通风处；
- 彻底修复需要 WhateverXe 上游处理后 eDP 唤醒链路训练，当前只能规避；
- 另一种极端的 ACPI 方案（屏蔽 `PNP0C0D` 合盖设备）未采用，本文不推荐默认使用。

## 黑屏后的恢复

系统仍在运行（SSH/Tailscale 还能连上）时，**不要长按电源强关**：

1. 远程执行 `sudo shutdown -r now`，重启后显示恢复；
2. 无法远程时，长按电源键 10 秒强制关机，再开机；
3. 强关前可先确认系统是否在线（SSH、Tailscale ping），避免误判死机。

## 回退（恢复正常的显示器自动睡眠）

如果以后 WEX 修复了该问题，想恢复正常的省电策略：

```sh
sudo launchctl bootout system/com.user.powermgmt-enforce 2>/dev/null
sudo launchctl bootout system/com.user.caffeinate 2>/dev/null
sudo rm -f /Library/LaunchDaemons/com.user.powermgmt-enforce.plist
sudo rm -f /Library/LaunchDaemons/com.user.caffeinate.plist
sudo rm -f /usr/local/bin/enforce-pmset.sh
sudo pmset -a disablesleep 0 displaysleep 10 sleep 10 lidwake 1
```

回退后合盖/闲置睡眠恢复正常策略，但 eDP 唤醒黑屏可能再次出现（属于显卡驱动层问题）。

## 与其他项目的关系

- 与内置麦克风（SST/PDM0）方案无冲突，本机两者同时启用正常；
- 与 HDMI 外接显示未修复问题是两件事：HDMI 端口目前不识别外接显示器，仍需后续处理。
