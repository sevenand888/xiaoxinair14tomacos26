# 隔空投送与互联

截至 2026-11-01，本机 Intel AX201 使用的 laobamac AirportItlwm Tahoe `8ae5115` 明确不支持 AWDL / AirDrop。当前文档将隔空投送记录为“未支持”。

官方 OCLP 的 Modern Wireless 补丁面向 Broadcom，恢复无线框架和相关系统组件。OCLP-CustoMac 增加了 Intel 检测与框架恢复，Intel 驱动仍由外部提供；其双向 AirDrop 成功记录来自 Broadcom 测试。KGP AirportItlwm-Tahoe 已实现部分 AWDL/P2P、AirPlay 和屏幕镜像功能，AirDrop 仍列为后续工作。因此，这些项目目前都没有提供本机 AX201 的 AirDrop 修复方案。

AirDrop 的完整过程包括 BLE 发现、点对点 Wi-Fi、身份协商和文件传输，功能验收应记录双向文件传输结果。

iPhone 镜像要求 Apple silicon 或真正配备 Apple T2 安全芯片的 Mac。OCLP 官方说明，此功能会因 T2 证明验证失败而无法连接。本机没有 T2；普通 AirPlay 屏幕镜像属于另一项功能。
