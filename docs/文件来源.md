## 系统安装资源

Sonoma 使用 Apple 的 InstallAssistant.pkg，版本 **14.8.9（23J631）**，大小 **13,654,790,295 字节**。原 U 盘的下载地址、Apple 完整性校验记录及 SHA256 已整理到 [Sonoma 安装包信息](../sonoma14/installer.json)。

Tahoe 使用 Apple 的 InstallAssistant.pkg，版本 26.7.1（25G241），大小 **18,380,974,544 字节**：

机器可读信息见 [tahoe26/installer.json](../tahoe26/installer.json)。

[Apple InstallAssistant.pkg](https://swcdn.apple.com/content/downloads/51/17/142-28081-A_616Q67X32N/5atqz1miz61kmrim7fwkn7yi62xuzzcc0s/InstallAssistant.pkg)

```text
SHA256 ca854f49dfdedbe78492c26d0e4172ee4d37573e2d375ca90c083d7615b6f48a
```

恢复镜像从 Apple 下载，使用 [OpenCore macrecovery 工具](https://github.com/acidanthera/OpenCorePkg/tree/1.0.8/Utilities/macrecovery)按其说明取得对应版本的 BaseSystem.dmg 和 chunklist。开机进入恢复环境后先核对 `sw_vers` 的系统版本。

AppleHDA 540.3 取自 **KDK 14.8.9（23J631）**。KDK 可从 [Apple Developer Downloads](https://developer.apple.com/download/all/?q=Kernel%20Debug%20Kit) 获取，提取过程、文件校验和 HAL 构建入口见音频构建说明。

Graphics 0.3.2 从 [WhateverXe-Graphics 官方发布页](https://github.com/b00t0x/WhateverXe-Graphics/releases/tag/v0.3.2)下载；资源工具会校验并存入本地 `tahoe26/downloads/`。

## 配置整理

Sonoma 保留原 18 步手册及其对应文件。Tahoe 最终配置取自修复完成的实际 EFI；安装配置依据成功安装时的修改记录复原。两套 OpenCore 均为 1.0.8 DEBUG，检查工具为 1.0.8 RELEASE。

已清除 SMBIOS 机器身份与无线预设。网络地址、账号口令、SSH 密钥、用户联系人、录音、诊断原日志、历史 EFI 副本、BIOS 镜像和系统安装镜像不放入仓库。

SST 驱动及发布工具保留成功产物的原始字节和签名。SimpleHDA 的新增补丁、构建工具与两个新增源文件放入仓库，AppleHDA payload 和 HAL 在本机准备。
